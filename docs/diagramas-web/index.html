Cómo leer los diagramas

▢ Acción o pantalla◇ Decisión▭ redondeado: inicio, fin o salida alternativa↗ Paso enlazado: abrir otro flujo

  • Las cajas verdes enlazadas y los enlaces al pie permiten pasar a otra funcionalidad. Después de completar un requisito, vuelve al flujo de origen.
  • Las ramas sin flecha de retorno terminan ese recorrido. Una alternativa puede cerrar la acción o indicar otra pantalla a la que acudir.
  • Para comenzar desde cero: C01 → D01 → D02 → D03 (donador), o C01 → E01 → E02 → E03 → E04 → E05 (emprendedor).
  • El superadministrador también puede utilizar las funciones del administrador. Para comentar necesitas una cuenta de donador o emprendedor.
  • Si una carga falla, reintenta desde el control disponible o vuelve a cargar la página. Si la sesión venció, inicia sesión de nuevo.
  • Los aportes utilizan saldo simulado. El acceso con Google todavía no está disponible; utiliza tu correo y contraseña para iniciar sesión.

Emprendedor / E03

Crear una campaña y guardarla como borrador

Dónde entrar: Mis Campañas → Lanzar Campaña · /entrepreneur-campaigns

Antes de empezar: Perfil completo e identidad KYC aprobada.

Ten en cuenta: Completa título de 5–50 caracteres, eslogan de 10–50, descripción de 50–800, meta de al menos Bs. 100 y una categoría. Añade al menos un documento de respaldo. La fecha de cierre puede omitirse al guardar un borrador, pero debe ser futura para publicar. El video opcional debe ser de YouTube o TikTok. Comprueba que la portada y los documentos se hayan cargado.
