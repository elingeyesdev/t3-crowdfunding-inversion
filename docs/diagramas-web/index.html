Cómo leer los diagramas

▢ Acción o pantalla◇ Decisión▭ redondeado: inicio, fin o salida alternativa↗ Paso enlazado: abrir otro flujo

  • Las cajas verdes enlazadas y los enlaces al pie permiten pasar a otra funcionalidad. Después de completar un requisito, vuelve al flujo de origen.
  • Las ramas sin flecha de retorno terminan ese recorrido. Una alternativa puede cerrar la acción o indicar otra pantalla a la que acudir.
  • Para comenzar desde cero: C01 → D01 → D02 → D03 (donador), o C01 → E01 → E02 → E03 → E04 → E05 (emprendedor).
  • El superadministrador hereda las funciones del administrador. Los módulos compartidos se usan según el acceso de cada cuenta; comentar exige rol donador o emprendedor.
  • Si una carga falla, reintenta desde el control disponible o vuelve a cargar la página. Si la sesión venció, inicia sesión de nuevo. Las condiciones específicas aparecen en cada flujo.
  • El dinero funciona como saldo simulado. Las operaciones disponibles solo por API y los controles aún desconectados se explican en los límites de la guía.

Se imprimen los diagramas que coinciden con la búsqueda; cada uno comienza en una página.

Alcance comprobado

Límites de los recorridos web

Estos hallazgos impiden presentar algunas capacidades del servidor como si fueran opciones navegables de la web.

  • Planes de fondos, hitos y movimientos financieros. Hay API y funciones cliente para crear o editar estos registros, pero no se encontraron formularios React conectados. La guía cubre consulta pública y auditoría administrativa; no inventa un recorrido de carga para el emprendedor.
    Fuentes
    • web/frontend/src/api/campaign.api.ts
    • web/routes/api.php
  • Asistente de campañas. AICampaignAssistant existe como componente y dispone de API, pero no está montado en una pantalla. El asistente de soporte de Inicio sí tiene un recorrido web (V07).
    Fuentes
    • web/frontend/src/components/AICampaignAssistant.tsx
    • web/frontend/src/pages/LandingPage.tsx
  • Reportes generales PDF/CSV. El servidor genera reportes de campañas, pero no se encontró un botón de descarga conectado en las pantallas web. Los comprobantes individuales PDF sí están incluidos en D05.
    Fuentes
    • web/app/Http/Controllers/InvestmentController.php
    • web/frontend/src/api/campaign.api.ts
  • Finalizar una campaña financiada. El servidor permite finalizar campañas financiadas, pero la tarjeta web solo ofrece Finalizar en estado Publicada. E10 documenta la regla del servidor y esta limitación de acceso.
    Fuentes
    • web/frontend/src/components/CampaignCard.tsx
    • web/app/Services/InvestmentEngine.php
  • Envío a revisión desde el formulario. En Mis Campañas se muestra un botón de envío en el formulario, pero no se pasa onSubmitForReview. El recorrido verificable es guardar el borrador y enviarlo desde la tarjeta o vista previa (E03–E04).
    Fuentes
    • web/frontend/src/pages/MyCampaignsPage.tsx
    • web/frontend/src/components/CampaignForm.tsx
  • Primer nivel de recompensa. La pestaña Recompensas de la vista previa se muestra solo si ya existen niveles. Agregar los primeros desde el formulario de campaña; después usar E08.
    Fuentes
    • web/frontend/src/components/CampaignPreviewModal.tsx
    • web/frontend/src/components/CampaignForm.tsx
  • Edición de archivos de respaldo. El formulario permite adjuntar respaldo y la vista previa permite consultarlo. No se encontró un control web conectado para borrar documentos, aunque existe un endpoint.
    Fuentes
    • web/frontend/src/components/CampaignForm.tsx
    • web/frontend/src/components/CampaignPreviewModal.tsx
    • web/routes/api.php
  • Eliminar perfil de donador. El manejador y la API existen, pero ProfileSidebar no utiliza onDeleteProfile. No se incluye como recorrido visible. El perfil de emprendedor sí ofrece esta acción (E12).
    Fuentes
    • web/frontend/src/pages/InvestorProfilePage.tsx
    • web/frontend/src/components/investor-profile/ProfileSidebar.tsx
  • Estados administrativos y reactivación. La API admite transiciones adicionales de campañas; no se encontró un selector conectado para ellas. Tampoco hay un control de reactivación de usuarios en la pantalla revisada.
