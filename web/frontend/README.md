# Interfaz React

El código de la interfaz está integrado con Laravel. Ejecuta `npm ci`, `npm run build` y `composer dev` desde la raíz del proyecto, y abre `http://localhost:8000`.

La configuración activa de Vite y las dependencias están en la raíz. `frontend/src` conserva las pantallas y componentes originales. El chat usa Laravel Echo y Reverb. Consulta `../README.md`.
